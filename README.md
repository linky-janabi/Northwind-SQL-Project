# Northwind-SQL-Project

This project explores real-world SQL techniques using the classic Northwind Traders dataset. It demonstrates how to analyze business operations—such as customer profitability, order tracking, and product performance—through practical, readable SQL queries.

## Project Overview

The primary goal of this analysis is to explore the Northwind database to gain insights into product sales and identify key trends that can enhance business performance. This involved a deep dive into sales data, specifically examining monthly sales patterns, cumulative growth, and top-performing product categories.

To achieve this goal, a combination of SQL queries and Python data analysis techniques was used. The analysis involved;
- calculating cumulative sales for product categories,
- identifying exceptional products based on sales metrics,
- visualizing sales trends to highlight growth areas.

## Why Northwind?
Northwind is a classic sample database that mirrors a fictional product distribution company. It's perfect for:
- Practicing SQL joins and aggregations
- Understanding window functions and common table expressions (CTEs)
- Building portfolio-ready SQL analyses
